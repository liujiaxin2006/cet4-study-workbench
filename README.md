# CET-4 Copilot

面向有高中英语基础、需要重新建立学习习惯的 CET-4 学习者。手机与电脑使用同一学习账号，进度保存到服务端。

在线工作台：https://cet4-study-jiaxi.floot.app/

## 目前支持
- 邮箱与密码注册、登录，按账号隔离学习记录。
- 注册邮箱统一小写并阻止重复；注册页二次确认邮箱和密码，限制短时间批量注册。
- 每日新词目标10 / 20词（默认20），每次最多5个新词并穿插到期复习；翻卡后按“没想起 / 想起但犹豫 / 独立想起”自评。
- 默认每天安排最多20个不同的旧词，可自愿继续到期复习；遗忘或犹豫词在本轮间隔重现，每日最多3次后安排隔日，避免无限循环。
- 保存本轮队列、学习结果、阅读作答、错题和翻译草稿，供其他设备继续。
- 单词和例句合成语音、可展开的例句中文。
- 阅读答案依据、听力原文隐藏、每日学习任务。
- 手机端首页 / 背词 / 练习 / 我的四项毛玻璃导航；电脑端侧栏导航，阅读原文与题目分栏。
- 简化首页与统一词库入口，字号、每日单词量和目标考试日期集中在设置。
- 学习时间按前台有效学习实时记录，支持暂停，定期及退出时同步；我的页面汇总学习记录和进度。
- 翻译原文支持点词提示，使用提示的练习单独标记；支持未提交草稿恢复与多设备版本冲突保护。

## 源码形态与运行边界
本仓库是 **Floot 项目源码快照**，最近一次同步日期为 2026-11-17。线上站仍由 Floot 构建与部署。
`floot/` 保持平台中的原始文件路径，排除了组件示例和编辑器历史。
这不是开箱即用的 Vite / Next.js 工程：Floot 提供路由、构建、API 请求适配和部署入口。
直接把仓库部署到 GitHub Pages **不能**运行登录和进度同步；需要后端与 PostgreSQL。

## 文件结构
- `floot/pages/`：首页、登录页与样式。
- `floot/components/`：词卡、登录表单及 UI 组件。
- `floot/helpers/`：词库、复习算法、认证与数据库辅助代码、测试。
- `floot/endpoints/`：注册、登录、会话、进度读写接口。
- `floot/static/__dev/dependencies.json`：导出时的依赖配置。

## 学习内容说明
线上旧版包含640个优先复习词及原创示例，另有管理员真题审核样本。当前版本改为读取服务端题库，逐组验证后开放；候选文件、可练题量和已完成题量分别统计。

导入增加本地中英文OCR、双栏版面恢复、原卷附录答案识别、题型完整性与选项验证。参考答案须来自答案表或明确解析，不能从试卷的第一个选项推断；不同来源的选项顺序不能盲目混用。平台导入仍执行所有权、资料清单哈希及格式校验，未通过的题组不会开放。发布前已备份原题库载荷，用户答题表未清空。

1000个候选词按已提取阅读材料统计，覆盖57个有可用阅读材料的候选卷条目、22场次、198篇去重材料。与MIT开放四级词典取交集，保守归并可明确还原的词形并排除功能词，按场次覆盖、材料覆盖、出现次数排序。属于部分语料候选考频，全文校对后仍会变化；不是完整十年最高频结论。原640词中的非重复词继续保留，既有学习记录不删除。

练习遵循先独立回忆、完整提交后看解析、错题与不确定答对题进入延迟复测；首次成绩与重练成绩分开。单词同日重复不拉长间隔，遗忘词需跨日到期成功后逐步恢复。复习仍使用保守启发式间隔，不是FSRS或经个人数据验证的最优算法。写作与翻译提供参考与检查表，不伪造官方分数。用户可设置本人考试日期和30/60/90分钟计划；倒计时按北京时间午夜更新，日期不代表已经核实的官方考试安排。

## 供朋友使用
已发布的网站是公开可访问的。朋友可以打开在线工作台，用自己的邮箱和密码注册；不同账号的学习进度分开保存，同一账号可在手机和电脑同步。
目前不发送邮箱验证或密码找回邮件。忘记密码可在登录页提交找回申请，管理员通过原有可信渠道核验本人后提供一次性恢复链接；申请本身不证明邮箱归属。新用户注册上限为每小时 60 个、滚动 24 小时 200 个，用来防止异常批量注册，不代表服务器的同时在线人数上限。
Floot 托管和数据库费用取决于实际流量与账号套餐；此项目只做了小规模链路检查，不能保证任意人数的并发性能。
