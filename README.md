# CET-4 Copilot

面向有高中英语基础、需要重新建立学习习惯的 CET-4 学习者。手机与电脑使用同一学习账号，进度保存到服务端。

在线工作台：https://cet4-study-jiaxi.floot.app/

## 目前支持
- 邮箱与密码注册、登录，按账号隔离学习记录。
- 注册邮箱统一小写并阻止重复；注册页二次确认邮箱和密码，限制短时间批量注册。
- 10 / 20 词分轮练习：先回忆、查看释义，再选择“记住了 / 没记住”。
- 到期词优先；遗忘词在本轮重现；连续遗忘三次暂存，稍后复习。
- 保存本轮队列、学习结果、阅读作答、错题和翻译草稿，供其他设备继续。
- 单词和例句合成语音、可展开的例句中文。
- 阅读答案依据、听力原文隐藏、每日学习任务。
- 手机端四项毛玻璃底部导航、横滑切换和「更多」入口；电脑端保留完整导航。

## 真题资料审核（2026-11-13）
已新增管理员专用 `/library-review` 审核区，并从管理面板提供入口。普通用户和未登录请求不能访问审核接口或原始文件。

这批用户提供的资料共有176份文件，覆盖2017.06—2026.06的22个场次目录；清单位于 `data/cet4-corpus/inventory.json`。清单记录文件SHA-256、页数、提取状态和重复线索，文件数量不代表已核验的试卷套数。76份PDF有低文字量页面，需要OCR或视觉检查；4份旧版Word需要转换。

当前仅2023.06第1套接入私有审核样本：55道客观题、1项写作、1项翻译；阅读有原文证据、定位、选项分析和复盘建议。答案提交后由后端返回，草稿按账号保存，版本冲突拒绝覆盖。音频尚待听审，不作为正式模考成绩。三份样本原始文件位于Floot私有存储，仓库不包含原卷、音频、解析正文或账号资料。其余年份尚未批量转成可作答题库，1000词统计尚未完成。

`database/cet-review.sql` 提供新增表结构。盘点脚本仅读取源文件：

```sh
python scripts/cet4_inventory.py --root YOUR_CORPUS_DIRECTORY --out data/cet4-corpus/inventory.json --texts YOUR_TEMP_TEXT_DIRECTORY
```

样本校验脚本需要私有的规范化JSON与原始文件，不在仓库内附带这些内容。

## 技术栈
前端使用 React 19、TypeScript、CSS Modules、React Router、Radix UI 与 TanStack Query；服务端由 Floot 提供接口运行环境，持久化使用 PostgreSQL + Kysely，认证使用 bcryptjs 和 jose。

## 源码形态与运行边界
本仓库是 **Floot 项目源码快照**，最近一次同步日期为 2026-11-13。线上站仍由 Floot 构建与部署。
`floot/` 保持平台中的原始文件路径，排除了组件示例和编辑器历史。
这不是开箱即用的 Vite / Next.js 工程：Floot 提供路由、构建、API 请求适配和部署入口。
直接把仓库部署到 GitHub Pages **不能**运行登录和进度同步；需要后端与 PostgreSQL。

## 文件结构
- `floot/pages/`：首页、登录页与样式。
- `floot/components/`：词卡、登录表单及 UI 组件。
- `floot/helpers/`：词库、复习算法、认证与数据库辅助代码、测试。
- `floot/endpoints/`：注册、登录、会话、进度读写接口。
- `floot/static/__dev/dependencies.json`：导出时的依赖配置。
- `database/study-progress.sql`：学习进度表初始化 SQL（先配置认证资源）。
- `assets/app-icon.png`：项目图标。
- `scripts/verify_export.py`：检查内部导入、文件完整性与常见密钥格式。
- `docs/DEPLOYMENT.md`：部署步骤和外部迁移边界。

## 学习内容说明
当前词库包含 **640 个优先复习词**。词汇来自本站教学精选词和开放授权词库，按学习优先级组织；该排序不是历年四级真题考频，也不等于完整考纲词表。
考点全景页列出官方现行笔试8个训练单元、12类主题场景、14项语法/篇章检查点、每日训练闭环、阶段路线，以及2023年12月至2026年6月18套公开自测页直达链接。另列Ulearning旧年份试卷条目与两个2015/2016—2026第三方资料目录，覆盖更长年份范围；各第三方页面自报的年份和套数未逐份核验。站内含8道原创题型练习；完整试卷在来源页打开，本站不复制整卷。
官方课程要求参考范围约4,500词和700词组；本站没有取得并逐题统计近15年全部试卷，所以不发布未经复核的“最高频”排名。社交平台资料只作练习方法参考；小红书公开索引未提供可独立复核的四级笔记正文，抖音检索结果用于归纳回原文找证据等方法，不将博主说法当作考频数据。
阅读、听力、翻译训练仍是本站原创练习；听力使用浏览器合成语音，不是真题录音。
复习间隔是简单启发式安排，不是经过个人数据校准的记忆模型；不能保证考试成绩。
线上旧版每日时长由学习者确认后记录。待发布后台增加独立的前台活跃计时，二者不混算。考试日期与目标分数是原项目配置，使用前请按本人考试安排调整。
