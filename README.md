# CET-4 Copilot

面向有高中英语基础、需要重新建立学习习惯的 CET-4 学习者。手机与电脑使用同一学习账号，进度保存到服务端。

在线工作台：https://cet4-study-jiaxi.floot.app/

## 目前支持
- 邮箱与密码注册、登录，按账号隔离学习记录。
- 注册邮箱统一小写并阻止重复；注册页二次确认邮箱和密码，限制短时间批量注册。
- 10 / 20 词分轮练习：先回忆、查看释义，再选择“记住了 / 没记住”。
- 到期词优先；遗忘词在本轮重现；连续遗忘三次暂存，稍后复习。
- 保存本轮队列、学习结果、阅读作答、错题和翻译草稿，供其他设备继续。
- 单词和例句合成语音、可展开的例句中文。
- 阅读答案依据、听力原文隐藏、每日学习任务。
- 手机端四项毛玻璃底部导航、横滑切换和「更多」入口；电脑端保留完整导航。

`database/cet-review.sql` 提供新增表结构。盘点脚本仅读取源文件：


## 技术栈
前端使用 React 19、TypeScript、CSS Modules、React Router、Radix UI 与 TanStack Query；服务端由 Floot 提供接口运行环境，持久化使用 PostgreSQL + Kysely，认证使用 bcryptjs 和 jose。

## 源码形态与运行边界
本仓库是 **Floot 项目源码快照**，最近一次同步日期为 2026-11-13。线上站仍由 Floot 构建与部署。
`floot/` 保持平台中的原始文件路径，排除了组件示例和编辑器历史。
这不是开箱即用的 Vite / Next.js 工程：Floot 提供路由、构建、API 请求适配和部署入口。
直接把仓库部署到 GitHub Pages **不能**运行登录和进度同步；需要后端与 PostgreSQL。

## 文件结构
- `floot/pages/`：首页、登录页与样式。
- `floot/components/`：词卡、登录表单及 UI 组件。
- `floot/helpers/`：词库、复习算法、认证与数据库辅助代码、测试。
- `floot/endpoints/`：注册、登录、会话、进度读写接口。
- `floot/static/__dev/dependencies.json`：导出时的依赖配置。
- `database/study-progress.sql`：学习进度表初始化 SQL（先配置认证资源）。
- `assets/app-icon.png`：项目图标。
- `scripts/verify_export.py`：检查内部导入、文件完整性与常见密钥格式。
- `docs/DEPLOYMENT.md`：部署步骤和外部迁移边界。

## 学习内容说明
线上旧版包含640个优先复习词及原创示例，另有管理员真题审核样本。待发布版本改为读取服务端题库，逐组验证后开放；候选文件、可练题量和已完成题量分别统计。

本地已从176份原始资料整理62个候选卷条目、2525道客观题候选，覆盖22个场次目录；其中两项为第2/3套合卷，不能当成62套完整核验试卷。扫描页完成525页中英文OCR缓存，解析仍有漏题、答案不明和合卷待拆分。全部候选通过导入格式检查，但格式通过不代表题目正确；原始资料和候选题面留在本地私有工作目录，没有提交到公开仓库。

本地2023.06第1套完成6组可练样本：30道阅读类客观题、写作和翻译各1项。3组听力等待音频核验，暂不开放；其余候选均保持待校对。该修订样本和新增练习数据表尚未写入生产环境。

1000个候选词按已提取阅读材料统计，覆盖57个有可用阅读材料的候选卷条目、22场次、198篇去重材料。与MIT开放四级词典取交集，保守归并可明确还原的词形并排除功能词，按场次覆盖、材料覆盖、出现次数排序。属于部分语料候选考频，全文校对后仍会变化；不是完整十年最高频结论。原640词中的非重复词继续保留，既有学习记录不删除。

练习遵循先独立回忆、完整提交后看解析、错题与不确定答对题进入延迟复测；首次成绩与重练成绩分开。单词同日重复不拉长间隔，遗忘词需跨日到期成功后逐步恢复。复习仍使用保守启发式间隔，不是FSRS或经个人数据验证的最优算法。写作与翻译提供参考与检查表，不伪造官方分数。用户可设置本人考试日期和30/60/90分钟计划；倒计时按北京时间午夜更新，日期不代表已经核实的官方考试安排。
